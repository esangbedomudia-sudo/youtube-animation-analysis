# Project 3 — YouTube Animation Title & Content Strategy Analysis

## Overview

This project analyzes the language used in YouTube animation video titles to identify patterns that may be associated with stronger audience performance.

Using the dataset collected in Project 1, this analysis examines title keywords and compares their average view performance to better understand how content positioning and title wording relate to audience reach.

This project introduces text-based analysis into the overall analytics workflow and demonstrates how structured data can be combined with simple natural language techniques to generate actionable insights.

---

# Objective

The objective of this project is to:

* Analyze the words used in YouTube animation video titles
* Measure the average performance of title keywords
* Identify high-performing title terms
* Explore how title language relates to audience engagement

The analysis includes:
