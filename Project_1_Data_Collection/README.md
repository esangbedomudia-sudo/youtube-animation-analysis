# Project 1 — YouTube Animation Data Collection

## Overview

This project focuses on collecting and preparing YouTube animation data for analysis.

Using the YouTube Data API, this project gathers animation-related video information and creates a structured dataset that can be used for exploratory analysis, visualization, and future machine learning applications.

This project represents the first stage of an end-to-end analytics workflow: collecting raw data and transforming it into an analysis-ready format.

---

# Objective

The objective of this project is to:

- Collect YouTube animation video data through API requests
- Extract relevant video performance metrics
- Organize collected information into a structured dataset
- Prepare data for future analytics projects

---

# Tools & Technologies

- Python
- YouTube Data API
- Pandas
- CSV Data Processing

---

# Data Collected

The dataset contains information related to YouTube animation videos, including:

- Video ID
- Search query category
- Video title
- Channel name
- Publication date
- Views
- Likes
- Comments
- Engagement metrics

---

# Workflow

1. Connect to the YouTube Data API
2. Search for animation-related content
3. Collect video metadata and engagement statistics
4. Clean and organize the collected information
5. Export the dataset for analysis
